Ethernet bridging connects multiple network segments at the Data Link Layer (Layer 2 of the OSI model) to function as a single network. Bridges intelligently filter and forward data by reading MAC addresses, reducing traffic congestion and improving overall speed. [1, 2, 3]  
The main types of Ethernet bridging include: 

• Transparent Bridge: The most common type; it operates invisibly to other network devices. It automatically builds a MAC address table to learn where devices are located, deciding whether to forward or block traffic based on that data. 
• Translational Bridge: Used to connect two entirely different types of networking technologies or protocols (e.g., translating between an Ethernet network and an older Token Ring system) by converting the data format. 
• Source Routing Bridge: A legacy bridging method designed for Token Ring networks where the data frame embeds its entire path or route, instructing the bridge exactly where to send it. 
• Multiport Bridge: Connects more than two network segments simultaneously. This technology laid the foundational architecture for modern multi-port network switches. [4, 5, 6]  

These bridge types can also be deployed across different geographical models: 

• Local Bridging: Connects LANs or switches in the same physical building or local area using physical cables. 
• Remote Bridging: Connects separate LANs located in different geographic areas over a Wide Area Network (WAN) or telecommunication lines. [1, 7]
